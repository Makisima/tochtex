HTML-СТРАНИЦЫ (8 штук)
─────────────────────
index.html
    Главная. Hero-блок, быстрые кнопки услуг, статистика, кейс, процесс работы,
    прайс-лист (динамическая подгрузка из prices.json), форма заявки.
    Навигация: Главная / Услуги / Калькулятор / О заводе / Контакты.
    Содержит: Schema.org (LocalBusiness), Yandex.Metrika 113089370.

about.html
    О заводе. История, факты, оборудование (Sodick, Durma, покрасочная камера).
    Содержит: Yandex.Metrika 113089370.

services.html
    Полный перечень услуг по 5 категориям:
    • Листовой металл (лазерная резка, пробивка, гибка, сварка)
    • Механообработка (токарка, фрезерка, шлифовка, электроэрозия, ЧПУ)
    • Покрытия (порошковая окраска, гальваника)
    • Сборка и монтаж (SMT, жгуты, электромонтаж)
    • Оснастка (пресс-формы, штампы, литьё пластмасс)
    Содержит: Yandex.Metrika 113089370.

contacts.html
    Контакты. Телефон, email, адрес, режим работы, схема проезда.
    Ссылка на реквизиты.
    Содержит: Yandex.Metrika 113089370.

calculator.html
    Калькулятор стоимости по 3 услугам:
    • Лазерная резка (материал + толщина + длина + срочность)
    • Координатная пробивка (толщина + режим «удар»/«метр» + количество)
    • Порошковая окраска (площадь + сложность профиля)
    Читает цены из data/prices.json (блок «калькулятор»).
    Отправляет события в Метрику: calc_open, calc_tab_switch, calc_result,
    calc_send, calc_form_submit.
    Содержит: Yandex.Metrika 113089370.

thanks.html
    Страница «Спасибо за заявку». Показывается после успешной отправки формы.
    Содержит: Yandex.Metrika 113089370 (цель «Заявка отправлена»).

requisites.html
    Юридические реквизиты ООО «Максимум» (ИНН, КПП, ОКПО, ОГРН, юр. адрес).
    Содержит: Yandex.Metrika 113089370.

privacy.html
    Политика конфиденциальности (152-ФЗ). Обязательна по закону.
    Содержит: Yandex.Metrika 113089370.

PHP
───
send.php
    Обработчик формы обратной связи. Принимает POST, валидирует данные,
    отправляет письмо через PHPMailer + SMTP (smtp.beget.com:465).
    Защита: honeypot, rate limiting (3 заявки/60 сек с IP),
    строгая MIME-валидация (finfo), лимит файла 30 МБ,
    is_uploaded_file(), finally-блок удаления tmp-файла.
    Конфиг — в /home/m/mmatve1x/tochtex.ru/config.php (вне public_html, права 600).
    НЕ содержит вызовов Метрики (серверный скрипт, не рендерится в браузере).

JAVASCRIPT
──────────
js/main.js
    Основной модуль сайта:
    • Загрузка прайс-листа из prices.json
    • renderPrices() — рисует таблицы
    • generateRowsFromCalc() — генерирует строки из блока «калькулятор»
    • switchPriceTab() — переключение вкладок прайса
    • Маска телефона (+7 (___) ___-__-__)
    • Плавный скролл по анкорам
    • Валидация формы перед отправкой

js/calculator.js
    Калькулятор:
    • Загрузка prices.json
    • 3 услуги: лазерная, пробивка, покраска
    • Расчёт: базовая цена + скидка за объём + коэффициент + НДС 22%
    • Динамический список толщин для лазера (зависит от материала)
    • Ограничение: для толщины >3 мм пробивка «за удар» недоступна
    • Валидация максимумов (10 000 м / 1 000 000 ударов / 10 000 м²)
    • Кнопка «Оформить заявку» заполняет форму
    • События Метрики: calc_open, calc_tab_switch, calc_result, calc_send,
      calc_form_submit

ДАННЫЕ

data/prices.json
    Единый источник цен. Структура:

    "лазерная":       { название, описание, калькулятор: {цены, скидки, ...}, примечание }
    "пробивка":       { название, описание, калькулятор: {цены_удар, цены_метр, ...}, примечание }
    "покраска":       { название, описание, калькулятор: {цены[], коэффициент_сложности, ...}, примечание }
    "прессформы":     { название, описание, колонки, строки, примечание }
    "гибка":          { ... }
    "сварка":         { ... }
    "гальваника":     { ... }
    "токарка":        { ... }
    "фрезерка":       { ... }
    "шлифовка":       { ... }
    "электроэрозионная": { ... }
    "чпу":            { ... }
    "сборочная_чпу":  { ... }
    "сборка_кондиционеров": { ... }
    "сборка_жгутов":  { ... }
    "литьё_пластмасс": { ... }
    "электромонтаж":  { ... }

    Блок «калькулятор» — только у 3 услуг (лазерная, пробивка, покраска).
    Блоки «колонки» + «строки» — у 14 услуг (отображаются в прайсе как таблица).

    ВАЖНО: файл должен быть без BOM. Проверка: head -c 3 data/prices.json
    Ожидаемо: 7b 0a 20 ({ \n пробел).

СЛУЖЕБНЫЕ ФАЙЛЫ
───────────────
.htaccess
    Apache 2.4 (Beget). Содержит:
    • Защита vendor/ (RewriteRule)
    • Отключение листинга директорий (Options -Indexes)
    • Запрет доступа к composer.json, composer.lock, README.md
    • Security headers: HSTS, X-Frame-Options, X-Content-Type-Options,
      Referrer-Policy
    • Запрет кэширования PHP
    ВАЖНО: синтаксис Apache 2.4 — «Require all denied» (не «Order allow,deny»).
    При ошибке 500 — переименовать в .htaccess_disabled, проверить сайт.

.gitignore
    Исключения Git:
    • config.php (пароль SMTP)
    • vendor/ (PHPMailer, ставится на сервере)
    • composer.json, composer.lock
    • .DS_Store, Thumbs.db

push_to_github.bat
    Windows-скрипт: git add . + git commit (авто) + git push origin main.
    Минус: сообщение коммита неинформативное («Auto-push: дата время»).

.github/workflows/deploy-beget.yml
    GitHub Actions. Ручной деплой (workflow_dispatch) с подтверждением.
    source: index.html,calculator.html,about.html,services.html,contacts.html,
            thanks.html,requisites.html,privacy.html,send.php,.htaccess,
            css,js,data,Images
    target: tochtex.ru/public_html/
    НЕ деплоятся: config.php, vendor/, composer.json, composer.lock
    Секреты: SSH_HOST, SSH_USER, SSH_PASSWORD (в GitHub Secrets).

ПРОВЕРКА BOM
────────────
Перед деплоем проверять все файлы:

    cd "/c/Users/W/Documents/Завод Рязань/Vebsite_zavod_Ryazan_2"
    for f in index.html about.html services.html contacts.html thanks.html \
             requisites.html privacy.html calculator.html \
             data/prices.json js/main.js js/calculator.js css/style.css \
             .github/workflows/deploy-beget.yml; do
        printf "%-40s: " "$f"
        head -c 3 "$f" | od -An -tx1 | tr -d ' \n'
        echo
    done

Ожидаемые значения:
    HTML-файлы:                   3c2144  (<!D)
    data/prices.json:             7b0a20  ({ \n )
    js/main.js:                   2f2f20  (// )
    js/calculator.js:             2f2f20  (// )
    css/style.css:                2f2a20  (/* )
    .github/workflows/*.yml:      6e616d  (nam)

Если где-то efbbbf — убрать BOM:
    sed -i '1s/^\xEF\xBB\xBF//' <файл>
