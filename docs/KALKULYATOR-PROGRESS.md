## ✅ ТД-5. Опция «С материалом / без материала» — ЗАВЕРШЕНО 03.10.2026

### Что сделано

- **Тумблер** «Без материала / С материалом» над вкладками услуг
- **Скрытие тумблера** для вкладки «Порошковая окраска» (материал не считается)
- **Блок «Параметры материала»** в панелях лазера и пробивки:
  - Категория материала (фильтруется по материалу резки)
  - Марка
  - Длина детали, мм
  - Ширина детали, мм
  - Количество деталей
- **Автозаполнение** полей при первом входе в режим «С материалом» (200 / 300 / 100)
- **Расчёт по целым листам**: `ceil(масса деталей / (масса листа × КИМ))`
- **Проверка габаритов**: деталь не больше 2500×1500 мм
- **Проверка цены**: если цена марки `null` — предупреждение «уточняется у менеджера»
- **Правильный НДС**: материал с НДС → выделяется обратным счётом (`/ 1.22`)
- **Кнопка «Оформить заявку»** блокируется, если режим «С материалом», но поля пусты

- `calculator.html` — тумблер, блоки материала, CTA «Позвонить»
- `js/calculator.js` — вся логика
- `css/style.css` — стили тумблера, блока материала

## ✅ ТД-6. КИМ (коэффициент использования материала) — ЗАВЕРШЕНО 03.10.2026

### Что сделано

- **КИМ = 75%** зафиксирован в коде (клиент не вводит)
- **КИМ используется** для расчёта количества листов
- **В интерфейсе клиента КИМ не показывается** — только «Листов 1500×2500: N шт»

### Обоснование отказа от клиентского КИМ

Клиент не знает реальный КИМ раскроя — это внутренний параметр. Если дать клиенту ввод — он либо занизит (нам убыток), либо завысит (клиент уйдёт). Фиксированные 75% — отраслевой стандарт.

### Файлы

- `js/calculator.js` — переменная `KIM = 0.75`, расчёт `sheetCount`
